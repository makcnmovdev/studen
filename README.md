# Студень

Расписание пар для студентов колледжей и вузов: открыл и сразу видно, что сегодня и завтра.

> Статус: бета. Первое учебное заведение — ЧЭМК (Чебоксары).

## Возможности

- расписание своей группы на сегодня, завтра и всю неделю, с числителем и знаменателем
- время пар с учётом изменённого расписания звонков, обеды, фильтр по подгруппе
- предмет, преподаватель, корпус, аудитория
- поиск преподавателей по алфавиту и аудиторий: где сейчас свободно и что идёт в кабинете
- уведомления о выходе расписания, о заменах, напоминание перед парой (за 10–60 минут, на выбор) и «Доброе утро» с погодой
- подписка на расписание в календаре телефона
- ИИ-помощник: отвечает про пары, преподавателей, аудитории и погоду, понимает голос
- объявления учебной части

## Установка

### Android

Скачайте последний `studen-x.y.z.apk` в разделе [Releases](https://github.com/makcnmovdev/studen/releases) или на сайте: «Настройки» → «Скачать для Android». Приложению не нужны Chrome и сервисы Google: оно работает на встроенном в Android движке.

Перед установкой сверьте контрольную сумму с файлом `SHA256SUMS` из того же релиза:

```
sha256sum studen-x.y.z.apk
certutil -hashfile studen-x.y.z.apk SHA256
```

Первая команда для Linux и macOS, вторая для Windows. Если сумма не совпадает, не устанавливайте файл.

### iPhone

Откройте [studen.makcnmobdev.com](https://studen.makcnmobdev.com) в Safari → «Поделиться» → «На экран Домой».

[studen.makcnmobdev.com](https://studen.makcnmobdev.com)
