# Студень

Расписание пар для студентов колледжей и вузов: открыл и сразу видно, что сегодня и завтра.

> Статус: в разработке. Первое учебное заведение — ЧЭМК (Чебоксары).

## Возможности

- расписание своей группы на сегодня и завтра
- время пар с учётом изменённого расписания звонков
- предмет, преподаватель, корпус, аудитория, подгруппа
- скоро: уведомления о выходе расписания на завтра и о заменах
- скоро: расписание на неделю, поиск по преподавателю

## Установка

### Android

Скачайте последний `studen-x.y.z.apk` в разделе [Releases](https://github.com/makcnmovdev/studen/releases).

Перед установкой сверьте контрольную сумму с файлом `SHA256SUMS` из того же релиза:

```
sha256sum studen-x.y.z.apk                    # Linux / macOS
certutil -hashfile studen-x.y.z.apk SHA256    # Windows
```

Если сумма не совпадает, не устанавливайте файл.

### iPhone

Через веб-версию: откройте сайт в Safari → «Поделиться» → «На экран Домой». Ссылка появится здесь после запуска.

### Браузер

Ссылка на веб-версию появится здесь после запуска.
